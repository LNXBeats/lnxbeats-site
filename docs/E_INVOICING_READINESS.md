# Facturation électronique — préparation 2026/2027

État vérifié le 28 août 2026, à revalider avec le professionnel comptable avant toute décision.

- réception de factures électroniques : obligation générale à compter du **1er septembre 2026** ;
- émission : TPE/PME et micro-entreprises à compter du **1er septembre 2027** ;
- la franchise en base de TVA n’exclut pas l’entreprise du dispositif ;
- les opérations B2B domestiques entrent dans la facturation électronique selon le champ légal ;
- les opérations B2C relèvent en principe de l’e-reporting selon le champ applicable ;
- quatre données supplémentaires annoncées doivent être prévues (SIREN client lorsque requis, adresse de livraison si différente, nature des opérations, option TVA sur les débits).

Phase 4B n’intègre aucune plateforme agréée, portail fiscal ou e-reporting. Gates futurs : identification de la plateforme, mandat/contrat, formats supportés, annuaire, statuts de cycle de vie, export comptable, archivage, reprise sur incident, test B2B et validation du comptable.

Sources : [Bercy](https://www.economie.gouv.fr/tout-savoir-sur-la-facturation-electronique-pour-les-entreprises), [impots.gouv.fr](https://www.impots.gouv.fr/professionnel/questions/franchise-en-base-micro-entrepreneur-ou-auto-entrepreneur-suis-je-concerne).
