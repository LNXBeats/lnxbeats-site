## Mécanisme normal d’approbation

L’approbation est une action Admin explicite sur `/admin/droits` : l’approbateur authentifié choisit le modèle exact et saisit une **référence de revue juridique réelle**. Le serveur enregistre simultanément l’état `APPROVED`, l’identifiant Admin, l’horodatage réel et la référence. Les contraintes PostgreSQL refusent un état approuvé incomplet. Cette action n’ouvre pas le commerce à elle seule : les gates runtime dédiés restent cumulatifs et absents par défaut.

Aucun timestamp, approbateur ou numéro de revue n’est prérempli dans ce dossier.
